# Форма — конструктор резюме (рабочий MVP)

Локально запускаемый веб-проект на Node.js (без внешних зависимостей), HTML/CSS/JS. Реализован по PRD/SPEC/DESIGN с тёплой палитрой, без градиентов, glow и glassmorphism.

## Запуск

```bash
node server.js
```

Откройте http://localhost:3000. Требуется Node.js 20+.

## Что работает

- Поля профиля, фото, контакты, опыт, образование, навыки, вакансия.
- Добавление/удаление мест работы и образования, живой предпросмотр, автосохранение в localStorage.
- Четыре шаблона и пять палитр.
- Отдельные редакторы мотивационного и рекомендательного писем.
- Экспорт через системную печать браузера: **Сохранить как PDF**, A4 или мобильная компоновка; для мобильного формата установите в диалоге печати подходящий размер страницы.
- Адаптивная мобильная версия с переключением редактор/предпросмотр.
- Серверный маршрут `/api/generate` для генерации описания, анализа, мотивационного письма и черновика рекомендации.

## Подключение ИИ

Задайте ключ в поле «Ключ и образец» внутри редактора. Подойдёт ключ Google AI Studio (он начинается с `AQ.`) или OpenAI. Ключ хранится в браузере и на локальном компьютере, в резюме не записывается и в GitHub не попадает. На опубликованном сайте каждый посетитель использует свой ключ.

## Границы MVP

Это **работающий локальный прототип**, а не production-система: нет регистрации, PostgreSQL, облачной синхронизации, серверной очереди PDF, проверки достоверности данных и развёрнутого набора автотестов. Экспорт PDF основан на печати браузера, а не отдельном серверном PDF-рендерере. Данные локального черновика доступны в профиле браузера, поэтому не вводите чувствительную информацию на общем компьютере. Для production потребуются аутентификация, база данных, серверная валидация, rate limiting, защита от злоупотреблений, управление согласиями и удалением данных.
